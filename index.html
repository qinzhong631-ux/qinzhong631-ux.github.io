PROJECT / 001PUBLIC REPOSITORY

MiniGPT ↗

Understanding GPT by building one.

An educational, character-level GPT-style language model built with PyTorch. The project includes a two-layer decoder-only Transformer, a training pipeline, controlled attention experiments, reproducible result records, and a local Gradio interface.
